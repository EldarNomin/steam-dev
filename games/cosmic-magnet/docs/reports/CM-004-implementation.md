# CM-004 — подготовка плейтеста (сдача GLM)

Задача / граница: CM-004 из DEVELOPMENT-PLAN.md — проверка интереса, решение о продолжении. **Код новых механик не добавляется** (по плану). Доля GLM: запускаемая Windows-сборка фрагмента и короткая анкета; живые сессии (5–10 человек), анализ наблюдений и 15-секундный ролик незнакомой аудитории — Эльдар (см. `docs/playtest/README.md`), не входят в эту сдачу.

Ветка / PR: `feat/cosmic-magnet/CM-004-playtest` (stacked на CM-003-ветку, база включает принятый `b926bc7`).

Движок / ОС: Godot 4.5.1 Standard; сборка — Windows x64 (windows-latest в CI).

## Что сделано

- `export_presets.cfg` — пресет «Windows Desktop»: `binary_format/embed_pck=true` (один `CosmicMagnet.exe` без отдельных pck), console wrapper включён (видно ошибки на машинах тестеров), кодирование/подпись выключены, архитектура x86_64. Пресет распознаётся движком (проверено локально: неверное имя отвергается, «Windows Desktop» проходит разбор конфигурации и доходит до проверки шаблонов).
- `.github/workflows/cosmic-magnet.yml` — job `windows-build` (windows-latest, только PR/workflow_dispatch): скачивает Godot 4.5.1 win64 + export templates, **SHA512 обоих архивов сверяется** с официальным `SHA512-SUMS.txt` релиза; headless-import; `--export-release "Windows Desktop"` с провалом по `SCRIPT ERROR|ERROR:`; **smoke экспортированного билда** (запуск без редактора, падение при мгновенном выходе); результат — артефакт `cosmic-magnet-windows-x64` (один exe).
- `.gitignore` — `build/` (бинарники в git не попадают, только артефакт CI — по правилам AGENTS.md).
- `docs/playtest/README.md` — инструкция Эльдару: что раздавать (артефакт CI), процедура сессии без объяснений, что замерять (T_понимания, T_покупки, подсказки, добровольные 5+ минут), сводная таблица, критерий решения «продолжать/один цикл правок/стоп», отдельный замер 15-секундного ролика.
- `docs/playtest/anketa.md` — анкета участника (по пунктам плана: понимание управления, время первой покупки, добровольное продолжение, раздражения, желание следующей версии) + поля наблюдателя.
- `README.md` игры — раздел «Плейтест (CM-004)»: откуда билд, куда складывать результаты.

## Ограничения и оставшиеся риски

- Экспорт не подписан (SmartScreen предупредит) — для круга знакомых Эльдара приемлемо; при шире раздаче — кодирование отдельной задачей.
- Console wrapper внутри билда позволяет тестерам показать лог при crash — просить скриншот `.console.exe` при проблемах.
- Билд содержит всю механику CM-003 (включая сохранение в `user://`) — на общей машине «NEW GAME» с подтверждением; на личных машинах конфликтов нет.
- Критерий решения и стоп-условие — в `docs/playtest/README.md`; выборка 5–10 человек не доказывает продажи (по плану).
