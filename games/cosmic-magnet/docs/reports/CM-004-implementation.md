## Что сделано

- `export_presets.cfg` — пресет «Windows Desktop»: `binary_format/embed_pck=true` (один exe с встроенным PCK), `debug/export_console_wrapper=2` (**копировать всегда** — режим 1 в release-экспорте обёртку не пишет; проверено по исходнику Godot 4.5.1: `copy_wrapper = (mode == 1 && p_debug) || mode == 2`), кодирование/подпись выключены, архитектура x86_64. Пресет распознаётся движком (локально: неверное имя отвергается, «Windows Desktop» доходит до проверки шаблонов).
- `.github/workflows/cosmic-magnet.yml` — job `windows-build` (windows-latest, PR/workflow_dispatch):
  - Godot 4.5.1 win64 и export templates скачиваются с **SHA512-проверкой каждого архива** по официальному `SHA512-SUMS.txt` релиза; оба лежат в кеше `~/godot-cache`;
  - **установка шаблонов (F1) не привязана к наличию редактора**: если в `%APPDATA%\Godot\export_templates\4.5.1.stable` нет `windows_release_x86_64.exe`, шаблоны разворачиваются из проверенного (кеш или свежая загрузка) TPZ независимо; финальная проверка существования валит шаг при их отсутствии; в лог печатается маркер «cache hit (exe restored before step)»;
  - headless-import; `--export-release "Windows Desktop"` с провалом по `SCRIPT ERROR|ERROR:`; smoke билда (запуск без редактора, падение при мгновенном выходе);
  - артефакт `cosmic-magnet-windows-x64` содержит **оба** exe: `CosmicMagnet.exe` и `CosmicMagnet.console.exe` (F2).
- `.gitignore` — `build/` (бинарники только в артефактах CI).
- `docs/playtest/README.md` — инструкция Эльдару: что раздавать (два файла артефакта, `.console.exe` — для диагностики), процедура без объяснений про игру, замеры T_запуска / T_вылета / T_понимания / T_покупки / подсказок / добровольных 5+ минут, сброс через подтверждённый NEW GAME на общей машине, сводная таблица с колонкой «понял цикл сам?
