# CM-H02 — один цикл после решения ITERATE

Основание: прямое поручение Эльдара «Продолжай» после PR #9. База и target — feat/cosmic-magnet/CM-H01-gameplay-hook, SHA 0deea37. Исполнитель Codex; сторонние этапы CM-005 не открываются.

## Результат

После расчистки 12 обломков и подбора модуля появляются 3 пары реле/крепление. Крепление не является прямой целью импульса и не собирается как лом. Реальная цепь от соответствующего реле разрывает одно ближайшее к магниту крепление за импульс. Три связи нужны для освобождения корабля. Крепления, реле и корабль — реальные узлы в прежнем лимите 40.

Для буксировки нужны модуль, импульс, сила 2, 20 свободного трюма и три снятых крепления. Корабль движется только во время активного импульса, не быстрее 160 px/s. Мышью направлять магнит к маяку. Захват магнитом на месте не заканчивает задачу: награда 100 и DOCK только при доставке в радиус 42 px EXIT BEACON. Новые числа находятся в balance.json.

## Приёмочные сценарии

- прямой импульс/сбор не снимает крепление; цепь снимает ближайшее выбранное реле, ровно один раз;
- нельзя буксировать корабль до снятия всех трёх креплений; нельзя получить награду вне маяка;
- корабль не движется без активного импульса или в паузе, не обходит силу/трюм;
- положение, снятые крепления и финал сохраняются между вылетами и перезапуском;
- старый профиль H01 с завершённой эвакуацией остаётся завершённым;
- сброс игры сбрасывает реле и буксировку; повреждённые ID/координаты отвергаются;
- полный маршрут из нулевого профиля проходится мышью без выдачи прогресса;
- анкета различает ранний финал и отказ играть.
