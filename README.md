# Космолов / Cosmic Catch — Unity MVP

Рабочее название, не проверено на занятость. Версия требований **0.1.0**, 7 октября 2026 года. Статус: спецификации и каркас Unity DEV-001; импорт, компиляция и Windows-сборка ещё не проверены в Editor.

Кооперативная охота на инопланетных существ для 1–4 игроков. Найти, понять повадки, поймать, доставить живым и улучшить оборудование. Пойманная добыча продолжает сопротивляться. На станции можно потратить личную игровую валюту на азартный терминал и случайные косметические капсулы.

## Первый запуск

Unity **6000.3.25f1** + Windows Build Support (Mono). Добавить папку репозитория в Unity Hub, открыть и дождаться импорта. Затем **Cosmic Catch → Setup → Create baseline**, открыть созданную `Assets/_Game/Scenes/Boot.unity` и нажать Play. Для exe: **Cosmic Catch → Build → Windows x64**.

Стартовая сцена создаётся самим Editor; в исходном каркасе её нет. Пока это неподвижная станция с геометрическими заглушками и экраном игры. Контроллер, охота, кооператив, экономика и азартные терминалы реализуются следующими задачами. [Полная инструкция и ограничения](Docs/Development/DEV-001.md).

## Правила работы

Один небольшой законченный результат за итерацию. Сначала работающий цикл и сетевой захват, затем дополнительный контент. `balance.v0.1.json` задаёт исходные числа; изменение правил сопровождается актуализацией спецификаций и сценариев.

Manifest задаёт прямые версии URP/Input System; успешное разрешение пакетов ещё не подтверждено. Сериализованные настройки, сцены, материалы и packages-lock.json нужно сохранить после первого импорта и Setup. Unity Editor/MCP в рабочей среде Codex не подключены. Bezi не обязателен.
